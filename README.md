# To-Do List
## Project 1 - Python Programming

A simple command-line To-Do List application built with Python.
The application stores tasks in a Python list.
Users can add new tasks to the To-Do List.
Users can view all available tasks.
Users can update an existing task.
Users can delete a selected task.
The program displays a menu for different operations.
Task numbers are used to update and delete tasks.
The program handles invalid task numbers.
It also handles invalid number inputs using try-except.
If there are no tasks, the program displays a suitable message.
The program continues running until the user selects `exit`.
## How to Run
Run the Python file using: `python todo.py`
## Features
Add, View, Update, Delete, and Exit tasks.
